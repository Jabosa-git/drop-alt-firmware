Default firmware for the Drop ALT keyboard.
Standard QMK builds I found broke USB hub passthrough for me but this one works.

Use [Massdrop/mdloader](https://github.com/Massdrop/mdloader) to flash


> Compiled from [Massdrop/qmk_firmware](https://github.com/Massdrop/qmk_firmware) (GPL-2.0). Note: the arm_atsam port contains Atmel CMSIS code with a redistribution restriction; this is shared for personal use with the Drop ALT (SAMD51).
